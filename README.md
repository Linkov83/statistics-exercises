## Setup

Use Python 3.10 or newer. The scripts were used with Python 3.14.

From the repository root:

```bash
python -m venv .venv
```

Activate in Windows Command Prompt:

```bat
.venv\Scripts\activate.bat
```

Or Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

On Linux or macOS:

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

## Run

Run these commands separately from the repository root:

```bash
python exercises/ex02/ex2a.py
python exercises/ex02/ex2b.py
python exercises/ex03/ex3a.py
python exercises/ex03/ex3b.py
python exercises/ex03/ex3c.py
python exercises/ex04/ex4.py
python exercises/ex05/ex5a.py
python exercises/ex05/ex5b.py
python exercises/ex09/ex9.py
```

Close the graph window to let each script finish. Exercise 5A prints its numerical results after the graph window closes.

Graphs are saved as PNG files in each exercise's `figures/` folder. Exercise 2 graphs are generated by its scripts and are not currently tracked in this repository.

## Conventions

- Sample standard deviation uses `n - 1`.
- Absolute frequencies sum to the number of observations; relative frequencies sum to 1, apart from rounding.
- The Shapiroâ€“Wilk test uses significance level 0.05. Not rejecting normality does not prove a normal distribution.
- Correlation describes linear association and does not establish causation.
